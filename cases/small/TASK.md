# Небольшая правка: подпись доступного остатка

В текстовом выводе `statusctl` замени подпись `Остаток` на `Доступно`.
Порядок строк, числа, подпись `Резерв`, JSON и правила ошибок должны сохранить
прежнее поведение. Дополнительные возможности не нужны.

Пример: `python3 -m statusctl --available 7 --reserved 3` должен вывести:

```text
Доступно: 7
Резерв: 3
```

Разрешены изменения `statusctl/**`, новые проверки `tests_solution/**` и
необязательный `docs/solution.md`. Следуй инструкции измерения из `AGENTS.md`.
Существующие контракты, задание, проверки и средства измерения не изменяй.
