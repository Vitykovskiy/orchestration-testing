# Контракт statusctl

`python3 -m statusctl` выводит две строки: доступный остаток и резерв. По умолчанию
значения равны 7 и 3; параметры `--available` и `--reserved` задают неотрицательные
целые числа. Отрицательное значение отвергается с кодом 2.

`--format json` выводит ровно `{"available":7,"reserved":3}\n` при значениях
по умолчанию. Порядок полей, отсутствие пробелов и завершающий перевод строки
сохраняются. Изменение требуется только текстовой подписи по TASK.md.
